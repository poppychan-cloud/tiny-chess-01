# tiny-chess-01 entry

A chess engine in a single `main.py` (under 4 KB) for the [tiny-chess-01 bounty on make.fun](https://make.fun/bounty/tiny-chess-01): 0x88 board, negamax/PVS, transposition table, quiescence, MVV-LVA ordering, piece-square tables, fixed node budget. The readable engine core is `engine.py`; `main.py` packs the full program (engine + search + env client). Run: `python3 main.py` (UCI over stdio).
