# tiny-chess-01 entry

A chess engine in a single `main.py` (under 4 KB) for the [tiny-chess-01 bounty on make.fun](https://make.fun/bounty/tiny-chess-01): 0x88 board, negamax with PVS alpha-beta, transposition table, quiescence search, MVV-LVA move ordering and piece-square-table evaluation, searching a fixed node budget per move. The readable source lives in `engine.py` + `engine2.py`; `main.py` is its packed form.

Run it (UCI over stdio):

```
python3 main.py
```
